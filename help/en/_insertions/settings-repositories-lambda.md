### Repositories on AWS Lambda

With [Redmine Kit AWS Lambda](../aws-lambda/lambda.md) on AWS Lambda, **Fetch commits automatically** and **Enable WS for repository management** are always off and shown disabled, with the note "Can't be set in this environment", and **Enabled SCM** offers only Subversion and Git (and the repository types built on them).
